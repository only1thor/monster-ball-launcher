# Monster Ball Launcher 🎮👾

A space-invader style game mixing in elements of monster capture.

Move your monster side to side with the arrow keys, and shoot balls to capture monsters with **Space**. Fire attacks with **Shift** to weaken or defeat the on-coming horde of monsters.

## Tech Stack

- **Platform:** Browser-based (HTML / JavaScript / Canvas)
- **Deployment:** GitHub Pages via GitHub Actions
- **Art:** Simple shapes, rendered as `.png` sprites

## V1 — Core Mechanics

- Player movement (left/right with arrow keys)
- Shoot capture balls (Space)
- Fire attacks (Shift) to weaken monsters
- Monsters approach from the top (horde-style)
- Capture / defeat mechanics
- Basic score tracking

## Development

```bash
# Serve locally
python3 -m http.server 8000
# or
npx serve .
```

Open `http://localhost:8000` in a browser.
